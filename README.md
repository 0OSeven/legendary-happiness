# Lift

A 4-day aesthetic training tracker built on evidence-based (Build with Science) principles.
Home program (45 lb kettlebell, 35 lb + 45 lb dumbbells, bench) progressing to a gym program.

- Streaks, weekly ring, and calendar
- Set-by-set logging with rest timer and progression tips
- Beginner → advanced phases (Foundation, Build, Deload, Intensify, Gym)
- Focus areas to bring up weak points

Data is stored on your device (localStorage). Open the GitHub Pages link on your iPhone in Safari,
then Share → Add to Home Screen.
